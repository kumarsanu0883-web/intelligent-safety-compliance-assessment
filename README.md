# Intelligent Safety Compliance Assessment

An AI-powered application that detects Personal Protective Equipment (PPE) compliance using Computer Vision and Deep Learning.

## Features

- PPE Detection (Helmet, Safety Vest, etc.)
- Real-time Camera Monitoring
- Image Upload Support
- Compliance Report Generation
- User-friendly Flask Web Interface

## Technologies Used

- Python
- Flask
- OpenCV
- YOLO
- HTML/CSS
- JavaScript

## Installation

```bash
git clone https://github.com/your-username/intelligent-safety-compliance-assessment.git
cd intelligent-safety-compliance-assessment
pip install -r requirements.txt
python app.py
```
